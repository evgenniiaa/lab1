## Домашнее задание к работе 1
### Условие задачи
Напишите программу, которая рисует кораблик/домик с помощью символов.

### 1. Реализация программы
```
#include <stdio.h>

void zadanie1()
{
    puts("   |\\    ");
    puts("   | \\   ");
    puts(" __|__\\_ ");
    puts(" \\_____/ ");
}

void zadanie2()
{
    puts("   /\\   ");
    puts("  /  \\  ");
    puts(" /____\\ ");
    puts(" |    | ");
    puts(" |____| ");
}

int main()
{
    zadanie1();
    zadanie2();
    return 0;
}
```

### 2. Результат работы программы
```
   |\
   | \
 __|__\_
 \_____/
   /\
  /  \
 /____\
 |    |
 |____|
```
